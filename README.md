# 聆涧 · LingJian

本机循环的环境声混音器。单轨或整类随机、混音无时限；播放页按场景浮现金句。曲库「此时·此刻·此地」按当地天气与时辰命中标签，随机组混并配静帧、动效与一句诗。

**耳畔清涧，一字生境。**  
鹿溪联合创新实验室 · 知行（耳·境）

```bash
npm install
npm run dev
```

打开 http://127.0.0.1:5173

默认绑定 `127.0.0.1`。Apple Comfort Sounds 仅供个人本机播放。完整素材（含系统背景音）只允许推送到 **私有** Git 仓库，禁止公开远程或公网分发。
