## 1. 实施改动全量清单

### 1.1 服务端安全与数据可靠性层
* **[P0] ULID 路由安全中间件** (`server/index.ts`)：
  在所有 `/api/mixes/:id` 路由前注入格式校验，对非 26 位 ULID 格式的请求直接返回 HTTP 400 (`invalid_id`)，阻断目录穿越与任意文件读取/删除路径。
* **[P0] 静态资源前缀越权防御** (`server/static.ts`)：
  重构 `safeJoin` 方法，显式使用 `path.resolve(root) + path.sep` 进行子目录边界比对，彻底修复对同前缀目录（如 `asset/SoundsWeb/`）的穿透漏洞。
* **[P1] POSIX 原子写文件** (`server/mixes.ts`)：
  `writeMix` 重构为先写入唯一临时文件 `mix.json.tmp.{timestamp}_{random}`，再通过 `renameSync` 进行原子替换，消除进程中断时 JSON 损坏风险。
* **[P2] macOS 隐藏文件容错** (`server/mixes.ts`)：
  `seedPresets` 与 `listMixes` 过滤 `.DS_Store` 等以 `.` 开头的隐藏文件，确保预设模板在各操作系统下均能正确加载。
* **[P0] 路径越界防御** (`server/mixes.ts`)：
  `mixDir` 增加绝对路径边界检查，超出 `data/mixes` 目录范围时强制抛出异常阻断。

### 1.2 Web Audio 引擎与生命周期层
* **[P1/P2] UI 渲染节流减负** (`src/audio/MixEngine.ts`)：
  `MixEngine.tick` 由每帧（60Hz/120Hz）全量 emit 降频为 100ms（10Hz）节流广播。大幅消除了 React 组件树在高频虚拟 DOM Diff 上的性能浪费与设备发热，同时保持平滑时间感知。
* **[P2] Safari/WebKit Autoplay 解锁** (`src/audio/MixEngine.ts`)：
  `arm()` 方法内引入 1 采样点无声 Buffer Kickstart，在用户手势触发时彻底激活底层硬件音频管线。
* **[P2] 硬件解码器加速释放** (`src/audio/MixEngine.ts`)：
  `Slot` 增加 `release()` 方法，在音轨停止（`stop`）与切换（`dropPlayers`）时显式置空 `audio.src` 并重置，避免触碰移动端 4-8 个硬件音频解码器上限。
* **[P3] 感知响度注释物理校正** (`src/audio/volume.ts`)：
  将平方律衰减注释中的分贝值由 $-6\text{ dB}$ 修正为物理严谨的 $-12\text{ dB}$。

### 1.3 视觉渲染与样式工程层
* **[P2] 异步图像载入竞态消除** (`src/effects/compositor.ts`)：
  `EffectCompositor.setBackground` 引入 `bgGen` 代数自增标记，在 `onload` 回调中校验代数一致性，杜绝快速切换场景时的“后发先至”背景图像覆盖错乱。
* **[P3] 生产依赖清理** (`package.json`)：
  将 `concurrently` 由 `dependencies` 迁移至 `devDependencies`，精简生产环境打包安装体积。
* **[P3] 样式内联规范化** (`src/styles/tokens.css`, `src/components/LegalGate.tsx`)：
  将 `LegalGate` 的内联 `<style>` 提取至全局 `tokens.css`，消除反复挂载组件时的 DOM 节点插入开销。
