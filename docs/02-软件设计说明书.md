## 1 引言

说明 V1.0 的体系结构、模块职责、数据与关键算法，使实现与需求可对照。早期英文底稿见 `design.md`。

## 2 体系结构

采用 **本地双进程**：Vite 提供 React SPA；Hono（Node）提供目录、混音 CRUD 与大文件 Range 服务。浏览器内 **MixEngine** 独占 Web Audio，**动效层** 与 **金句层** 只读引擎快照与目录标签。

```
┌────────────── 浏览器 ──────────────┐
│  LegalGate → LibraryPage / PlayPage │
│  Zustand 草稿    MixEngine 快照     │
│  RainGlass / WaterRipple / 2D FX    │
│  VerseCycle                         │
└─────────┬───────────┬──────────────┘
          │ /api      │ /sounds /backgrounds /poetry
┌─────────┴───────────┴──────────────┐
│  Hono 127.0.0.1:8787               │
│  catalog · mixes · ranged static   │
└─────────┬───────────┬──────────────┘
          │           │
   asset/Sounds    data/mixes/<id>/mix.json
   asset/Backgrounds
   asset/Poetry
```

**关键决策（摘要）**

| 决策 | 选择 |
| :--- | :--- |
| 框架 | Vite 5 + React 19 + TypeScript + Hono，不用 Next.js |
| 音频 | `MediaElementAudioSourceNode` 双槽；长文件流式 |
| 交叉淡化 | 余弦均衡功率 |
| 背景 | 31 张预置静帧 + 标签命中加权随机，无运行时生成 |
| 混音存储 | 磁盘 JSON；ULID 由客户端生成 |
| 绑定 | 默认 `127.0.0.1` |

## 4 进程与运行时

1. `npm run dev` 同时拉起 Vite（5173）与 `tsx watch` 的 Hono（8787）。  
2. Vite 将 `/api`、`/sounds`、`/backgrounds`、`/poetry` 代理到 Hono。  
3. 生产：`vite build` 静态资源；Hono 可挂 SPA fallback（见工程底稿 K15）。  
4. 离开 `/play*` 时引擎停止；刷新 `/play` 不停止，由会话模块把状态收敛为「暂停待继续」。

## 5 数据设计

### 5.1 声音目录

权威源：`asset/Sounds/catalog.json`（88 文件）。运行时由 `server/catalog.ts` 补充 `url`、`playback`、`standalone_scene`。

类别与推荐动效（标签并集，见 6.7）：

| 类别 id | 中文 | 动效 |
| :--- | :--- | :--- |
| noise | 噪音类 | grain |
| traffic | 交通出行类 | parallax |
| fire | 篝火 | embers |
| rain | 雨声 | raindrops（WebGL 玻璃雨，失败则 2D） |
| ocean | 海洋 | waves |
| stream | 溪流 | ripples |
| night | 夜晚 | fireflies |
| thunder | 雷雨 | lightning + raindrops |
| drive | 醒律（独立场景） | pulse + embers + parallax |

`quietnight`、`drive`：`standalone_scene = true`，洗牌池排除，曲库以「场景」卡片出现。

### 5.2 混音模式（逻辑结构）

```
Mix {
  schema_version: 1
  id: ULID
  name, created_at, updated_at
  master_volume: 0..1
  tracks[0..8]: {
    id: ULID
    kind: file | category
    target_id, volume, muted
    fade_in_ms, fade_out_ms, loop
  }
  shuffle: { seed?, avoid_last_n }
}
```

持久化路径：`data/mixes/<id>/mix.json`。PUT 时 URL id 与 body id 必须一致。

### 5.3 静帧目录

`asset/Backgrounds/catalog.json`：31 张。匹配输入为当前文件 id、类别 id、此刻标签与静帧 tags。

打分（`src/backgrounds/match.ts`）：

- 声音标签（出现在静帧词表 / `defaults` / 文件·类别映射里的）为 **core**：命中加分、静帧多出的标签减分、core 缺失减分。  
- 时辰、冷暖等意境标签为 **flavor**：命中微加分，不因缺失罚分。  
- `defaults[fileId|categoryId]` **只给对应静帧加分**，不再短路成「永远同一张」。  
- 在所有正分静帧中按 `exp((score-best)×1.35)` 加权随机；种子为本次混音 `mix.id`，同一次播放内稳定，下次进页可换图。  
- 无正分时才回退 `defaults` 或 `fallback_id`（白雾）。

动效 = 命中静帧的 `effects[]` **并上** `effectsFromTags(播放标签)`。雨一定带 `raindrops`，火带 `embers`，多轨叠加（雨+火=玻璃雨+余烬）。

### 5.4 金句

`asset/Poetry/quotes.json` 等约 1508 条去重摘句；`tags.json` 的 `sound_map` 将声音标签扩到诗文标签。抽取：权重 − 已展示次数惩罚，避免连抽同一 id。停留到期后淡出约 0.9 s，再抽下一句；计时器用 cycle 世代，不因 `pool` 引用变化而掐断。诗文在舞台与 HUD 之间、靠左，不覆盖右侧混音条。

### 5.5 播放会话

`sessionStorage` 键 `voicestream_play_session`：`{ path, status, sessionSec }`。刷新同路径时 `holdInterrupted`，UI 为「继续」。

## 6 关键算法

### 6.1 交叉淡化

双 HTMLAudio 槽。切歌时对增益施加余弦升/降曲线（均衡功率）。预取失败则当前轨继续（必要时 loop），避免空洞。

### 6.2 音量

界面线性 0–1，增益 `v²`（平方律），符合听感。

### 6.3 玻璃雨生命周期

RaindropFX 依赖 zogra 全局 GL 上下文与模块级着色器。播放页卸载时 **只暂停并移出 DOM，不 loseContext**。再次进入将同一 canvas 接回插槽。失败则透明度 0，2D 雨丝/水珠回退。

挂载顺序：先 `setEffects` 让 2D 立刻可见；再异步 `RainGlass.setScene` / `WaterRipple.setScene`；成功后从 2D 列表拿掉已由 WebGL 承担的 `raindrops` 或 `ripples`。依赖键为静帧 id 与动效签名字符串，**禁止**把每帧引擎快照或 `momentTags ?? []` 新数组放进该 effect，否则 autoplay 会在 80 ms 内反复取消，2D 与 WebGL 都挂不上。

### 6.4 涟漪此落彼涨

`sampleRippleBeat()`：抽取权重 `u∈[0,1]`，

- 强度 `amp ≈ 0.24 + u·0.78`（夹紧后约 0.22–1.06）  
- 间隔 `wait ≈ 0.48 + u·2.7` 秒（约 0.4–3.6 秒）  

再加独立抖动。`u` 大则圈强、下一圈更晚。

### 6.5 时辰与天气标签

当地钟点切分为子夜 / 黎明 / 清晨 / 正午 / 午后 / 黄昏 / 入夜。天气码（Open-Meteo WMO）归为晴、云、雾、毛毛雨、雨、雪、雷暴。时辰表与天气表各自贡献声音标签与意境标签，雨/雷暴会压掉海、溪等白天气象源。

「此时·此刻·此地」用命中的 `soundTags` 从目录里加权随机抽 2–4 轨（室内雨偏好屋瓦雨）。播放页把 `momentTags` 并入 `tagsFromPlay`（缺省用模块级空数组常量，避免每帧新 `[]`）。静帧与动效走 5.3 / 6.7；金句展开表含 dawn / dusk / midnight / storm。

天气栏抽诗：与播放页同一套 `expandTags` + `scorePool` + `pickWeighted`。每次曲库页挂载（刷新或从播放返回）抽一次；签名为 `天气|时辰|声音标签`，不随秒针重抽。只渲染 `quote.lines`。

### 6.6 刷新与自动播放策略

| 场景 | 行为 |
| :--- | :--- |
| 曲库点击播放 | 同一手势内 `arm()` + `start()` |
| 播放页刷新 | 忽略 history 中 autoplay；按钮「继续」 |
| `play()` NotAllowedError | 引擎状态为 paused，不得标 playing |
| pointerdown | 仅 `arm()`，避免与按钮 click 抢暂停 |

### 6.7 标签并集动效

`effectsFromTags(tags, still.effects)`：静帧自带特效与标签签名特效做并集。雨/屋瓦雨 → raindrops；雷/暴 → lightning+raindrops；火 → embers；溪/汽 → ripples；海 → waves；夜/静夜 → fireflies；行旅 → parallax；噪 → grain；醒律 → pulse+embers+parallax。多轨只并集、不互斥。

### 6.8 右侧混音条

原细条样式（11 px 轨名 + 2 px 白条 + 音量），不是卡片。有引擎玩家时以 `snap.current` 为准（**当前文件**名与 `currentTime/duration`）；尚无玩家时回退 `mix.tracks`。类别洗牌没有「总进度」——细条只表示这一首，切下一首从左重走。底部 `HH:MM:SS 循环中 · 无时限` 才是会话时钟。

## 7 界面设计要点

- 曲库：左场景与分类、中文件、右混音草稿；顶栏品牌、关于、「此时·此刻·此地」。  
- 播放叠层：`.stage`（静帧 → 玻璃/水面 WebGL → 2D → 暗角）z-index 0；金句 z-index 8 靠左；HUD z-index 40（全屏透明，不 `isolation`/`translateZ`，以免盖住 WebGL）；混音条 z-index 50。  
- 色板：鹿溪绿 `#0D5E42`、进化蓝 `#00D2FF`、标题金 `#F1C40F`、源启白 `#F5F7FA`；播放页正文偏暖纸色。

## 8 异常与降级

| 情况 | 处理 |
| :--- | :--- |
| 目录或混音 404 | 播放页错误文案，不崩溃 |
| WebGL 不可用 | 隐藏 WebGL 画布，2D 回退 |
| 音频超时 | 预取失败则延长当前 |
| 非回环 HOST | 进程拒绝启动 |

## 9 测试要点（验收对照）

1. 法律门 → 曲库 → 单文件 / 类别 / 混音播放均出声。  
2. 8 轨同时、类别切歌无静音空洞。  
3. 雨景二次进入背景不被黑画布淹没。  
4. 溪流涟漪有强有弱、疏密相反。  
5. 刷新播放页按钮为「继续」，一点即出声。  
6. 金句更换时动效不停；停留到期后换下一句，不得消失后不再出现。  
7. 停止回库后引擎空闲。  
8. 曲库点播放（autoplay）雨景仍有玻璃雨或 2D 雨丝，篝火仍有余烬。  
9. 右侧混音条显示当前文件名，细条随该文件进度走动，不是底部会话时钟。  
10. 同一雨标签多次进页，静帧可在命中集合内变化，且始终带雨类动效。
