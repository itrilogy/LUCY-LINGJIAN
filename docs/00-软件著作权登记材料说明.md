## 2 软件简介（申请表「软件功能和技术特点」）

聆涧是运行于本机的环境声混音软件。用户可按类别浏览舒适环境声，将单文件或整类别编入最多 8 轨的混音，无限循环播放；整类轨道在池内随机选取下一首并做均衡功率交叉淡化。播放页根据当前文件/类别标签从预置静帧库中匹配背景，叠加类别动效（如玻璃水珠、水面涟漪、萤火、余烬）与加权轮换的中文金句。曲库可按当地时辰与天气命中标签随机组成「此时此刻」混音，天气栏同步展示时间、气象与一句匹配诗文。混音配置以 JSON 文件保存在本机磁盘。服务器仅绑定 `127.0.0.1`，不提供公网分发。

技术特点：Web Audio 双槽交叉淡化；标签命中背景匹配；WebGL 玻璃雨与水面折射与 Canvas 2D 动效分层；时辰/天气标签此落彼涨地组混；会话刷新后以「继续」承接播放意图。
