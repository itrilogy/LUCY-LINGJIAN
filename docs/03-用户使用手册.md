## 1 软件是什么

聆涧是跑在你自己电脑里的环境声混音器。把雨、溪、火、夜等本机声音单轨或混在一起循环；播放时配上场景静帧、一层轻动效，偶尔浮出一句诗文。

标语：**耳畔清涧，一字生境。**  
出品：鹿溪联合创新实验室。

**请只在本机使用。** 系统舒适环境声来自 macOS Comfort Sounds，不能放到网上或发给别人。

## 2 运行环境

- 操作系统：macOS（设计目标）；其他桌面系统未作为交付环境。  
- 浏览器：最新 Chrome 或 Safari。  
- 已安装 Node.js 18 或更高。  
- 工程目录中已包含 `asset/Sounds`（约 508 MB 音频）。

## 3 启动

在工程根目录：

```bash
npm install
npm run dev
```

浏览器打开：`http://127.0.0.1:5173`

前端默认 5173，接口默认 `127.0.0.1:8787`。不要改成公网地址。

生产构建：

```bash
npm run build
npm start
```

（以仓库 `package.json` 脚本为准。）

## 4 第一次进入

全屏法律说明。阅读后点 **「我了解，进入」**。本机记住这次确认，下次不再挡。

## 5 曲库页

三栏：

1. **类别**：噪音、交通、篝火、雨、海、溪流、夜晚、雷雨。  
2. **文件列表**：点文件可加入混音或直接播放。  
3. **混音草稿**：最多 8 条轨道。轨道可以是「一个文件」或「整个类别」。

「安静的夜晚」「醒律」是 **独立场景**，不和夜晚 1–6 或其他类别一起随机切。醒律是一段带贝斯、吉他与鼓点的能量场景。

### 5.1 常用操作

| 操作 | 做法 |
| :--- | :--- |
| 只听一个文件 | 该文件上的播放 |
| 听一整类（随机切） | 类别的播放 |
| 加入混音 | 添加到右侧草稿 |
| 调音量 / 静音 | 轨道滑杆与静音 |
| 保存混音 | 起名后保存；可再载入、删除 |
| 播放当前草稿 | 草稿区播放 |
| 关于 | 左侧「关于」；播放页「i」 |
| 此时·此刻·此地 | 关于右侧。按当地天气、时辰与地点命中标签，随机组成混音并播放 |

侧栏分界可拖动，宽度会记住。

### 5.2 天气栏（右侧下方）

混音栏下约三分之一为「此时·此刻·此地」：

- 大号当地时间、日期、温度与天气（晴 / 雨 / 雷暴等）  
- 命中标签芯片（雨、夜、室内…）  
- 一句按这些标签抽到的诗文，**只显示诗句**  

刷新页面或从播放页点「曲库」回来，诗句会重新随机。钟点走动不会换句。首次可能询问定位；不允许则用大致网络位置，再不行就只按时辰组混音。

## 6 播放页

全屏画面。左侧是诗文；右上是当前各轨；底部是会话时间与按钮。

| 按钮 | 作用 |
| :--- | :--- |
| 播放 | 从未开始时启动 |
| 暂停 | 正在出声时停下 |
| 继续 | 暂停后恢复；**刷新页面后也显示「继续」**，点一次即可出声 |
| 停止 | 结束并回曲库 |
| 下一首 | 仅当混音里有「类别」轨道 |
| 金句停留 | 调整一句诗在屏上的时间 |
| 主音量 | 总音量 |

### 6.1 键盘

| 键 | 作用 |
| :--- | :--- |
| 空格 | 播放 / 暂停 / 继续 |
| Esc | 关闭关于；或停止并回曲库 |
| → | 类别轨道切下一首 |

### 6.2 画面

静帧按你正在听的声音 **标签命中** 后，在得分接近的几张里随机一张（同一次播放内不变）。不会在播放时向网上生成图片。多轨会把动效叠在一起，例如雨+火同时有玻璃雨和余烬。

| 你在听 | 可能看到 |
| :--- | :--- |
| 雨 | 玻璃水珠（窗外雨意）；WebGL 失败时仍有 2D 雨丝 |
| 溪流 | 隔着水面看水底的涟漪 |
| 火 | 余烬 |
| 夜 | 萤火 |
| 雷 | 间或闪白，并常带雨 |
| 醒律 | 节拍闪光、余烬与轻微位移 |
| 噪音 / 交通 | 胶片颗粒或位移感 |

诗文按声音标签挑选，多在左侧，横排/竖排会变。一句停留结束后会换下一句。诗文更换 **不会** 打断水珠或涟漪。

### 6.3 右侧混音条

每一行是 **当前正在出声的那一首**（类别随机时会变成「雨声 13」这种具体文件），下面一条细白线是这一首播到哪里。随机类别 **没有总进度**——切到下一首，细线从左边重新走。

底部中间的 `00:15 循环中 · 无时限` 是进页之后过了多久，和混音条不是一回事。

### 6.4 刷新了播放页

浏览器不允许没有点击就出声。刷新后：

- 按钮是 **「继续」**（不会再错写成「暂停」）；  
- 计时尽量接着刷新前；  
- **点一次「继续」** 就会出声。

从曲库点播放进来，仍会直接开始。

## 7 声音从哪来

| 来源 | 使用方式 |
| :--- | :--- |
| macOS 辅助功能「背景音」Comfort Sounds | 仅本机个人听 |
| 雷雨 WAV（BigSoundBank） | CC0 |
| 两段雷雨 MP3（OrangeFreeSounds） | 免费，须保留署名（关于页已写） |

请勿把 `asset/Sounds` 里的 Apple `.m4a` 推到公开仓库或服务器。

## 8 故障排除

| 现象 | 处理 |
| :--- | :--- |
| 打不开页 | 确认 `npm run dev` 两个进程都在；访问 127.0.0.1 而非局域网 IP |
| 没声音 | 看按钮：若是「继续」点一次；检查系统静音与主音量 |
| 刷新后要点两次 | 应已修复；若仍是「暂停」却无声，硬刷新后再试 |
| 雨的背景先出现再变黑 | 应已修复；从曲库再进一次播放页 |
| 动效全无（无雨珠/无余烬） | 硬刷新后再从曲库点播放；动效应随声音标签出现 |
| 金句只出一次就没了 | 应已修复；停留时间到了会换下一句 |
| 法律门反复出现 | 允许本站使用本地存储 |

## 9 隐私

无账号、无云。混音存在你电脑的 `data/mixes/`。法律确认与音量偏好存在浏览器本地。不向实验室回传聆听内容。
