## 1 引言

### 1.1 目的

规定「聆涧」V1.0 的范围、功能需求、非功能需求、接口与约束，作为设计、实现、测试与软著说明书的需求基线。

### 1.2 范围

软件在本机浏览器中提供环境声的浏览、编配与无限循环播放，并为播放过程匹配预置静帧、类别动效与中文金句。不包含账号体系、云同步、公网分发、运行时图像生成。

### 1.3 定义

| 术语 | 定义 |
| :--- | :--- |
| 曲库 | 按类别组织的环境声索引页 |
| 轨道 | 混音中的一条声源，种类为「文件」或「类别」 |
| 类别轨道 | 在该类别洗牌池中依次选取文件并交叉淡化 |
| 独立场景 | `quietnight`（安静的夜晚）、`drive`（醒律），不进入对应类别洗牌池 |
| 静帧 | `asset/Backgrounds` 中预生成的静止图像 |
| 金句 | 与当前播放标签加权匹配的文言/诗词摘句 |
| 法律门 | 首次进入前的本机使用声明确认 |

### 1.4 参考

- 本目录 `00`、`02`、`03`、`04`  
- `shared/mixSchema.ts`、`shared/catalog.ts`  
- `asset/Sounds/catalog.json`、`asset/Backgrounds/catalog.json`

## 2 总体描述

### 2.1 产品前景

将已整理的本机舒适环境声从「文件清单」变为可听、可混、可循环的聆听空间，并以「耳畔清涧、一字生境」完成声与诗的同屏。

### 2.2 用户

本机个人用户。不设角色分级。须年满可独立确认法律门之年龄（由使用者自行保证）。

### 2.3 运行环境

见 `00` 第 1 节。服务器进程与前端开发服务均绑定 `127.0.0.1`（默认端口 8787 / 5173）。

### 2.4 约束

1. Apple Comfort Sounds 仅本机个人使用，禁止再分发。  
2. 播放页背景不得在运行时调用图像生成接口。  
3. 单混音最多 8 条轨道。  
4. 非回环绑定须显式环境变量 `VOICESTREAM_BIND_LAN=1`。  
5. 浏览器自动播放策略：无用户手势不得出声；刷新后不得将「无声」标成「播放中」。

### 2.5 假设

用户使用桌面浏览器；本机磁盘可读写 `data/mixes/`；音频编解码支持 AAC-LC（`.m4a`）、MP3、PCM WAV。

## 3 功能需求

需求编号规则：`FR-模块-序号`。优先级：M 必须 / S 应当 / C 可以。

### 3.1 法律与品牌（FR-LG）

| 编号 | 需求 | 优先级 |
| :--- | :--- | :--- |
| FR-LG-01 | 首次进入须展示法律门，确认后进入曲库；确认状态保存在本机 | M |
| FR-LG-02 | 界面中文产品名为「聆涧」，英文「LingJian」，出品方为鹿溪联合创新实验室 | M |
| FR-LG-03 | 关于页展示标语、法律摘要、雷雨与玻璃雨第三方署名、实验室主标 | M |

### 3.2 曲库（FR-LB）

| 编号 | 需求 | 优先级 |
| :--- | :--- | :--- |
| FR-LB-01 | 按 8 个类别列出文件：噪音、交通、篝火、雨、海、溪流、夜晚、雷雨 | M |
| FR-LB-02 | 「安静的夜晚」「醒律」以独立场景卡片出现，不进入对应类别洗牌 | M |
| FR-LB-03 | 可将文件或整类别加入草稿混音；支持轨道音量、静音、删除 | M |
| FR-LB-04 | 草稿可命名、保存、列出、载入、删除；标识为 ULID | M |
| FR-LB-05 | 提供「播放文件 / 播放类别 / 播放混音」入口，进入播放页并自动开始 | M |
| FR-LB-06 | 主音量可调；侧栏宽度可拖拽并记住 | S |
| FR-LB-07 | 曲库左侧「关于」旁提供「此时·此刻·此地」：按当地时辰与天气标签随机组混音并进入播放 | M |
| FR-LB-08 | 曲库右侧栏下方约 1/3 展示当地时间、天气与命中标签；按同一套标签抽取诗文，只显示诗句 | M |
| FR-LB-09 | 天气栏诗文在页面刷新或从播放页返回曲库时重新随机，不随秒针跳动换句 | M |

### 3.3 播放引擎（FR-EN）

| 编号 | 需求 | 优先级 |
| :--- | :--- | :--- |
| FR-EN-01 | 支持单文件循环、类别洗牌、混音同时最多 8 轨 | M |
| FR-EN-02 | 类别轨道：预取下一首；避免紧接重复（池大小 > 1）；交叉淡化为均衡功率（余弦） | M |
| FR-EN-03 | 下一首未就绪时延长当前，不得出现静音空洞 | M |
| FR-EN-04 | 长文件（时长或体积超阈，含 QuietNight 等）以媒体元素流式播放，短文件可缓冲 | M |
| FR-EN-05 | 音量映射为平方律增益 | M |
| FR-EN-06 | 播放 / 暂停 / 继续 / 停止；类别轨支持「下一首」 | M |
| FR-EN-07 | 会话计时为经过时间，混音无共享曲长；底部时钟显示会话秒，不是混音条 | M |
| FR-EN-08 | 刷新播放页：不得把无声状态显示为「暂停」；若刷新前在播或已暂停，按钮为「继续」，一次点击恢复出声 | M |
| FR-EN-09 | `play()` 须在用户手势同步路径内触发；pointerdown 只武装 AudioContext，不抢按钮语义 | M |
| FR-EN-10 | 播放页右侧列出当前各轨正在播放的文件名与音量；细条为该文件 `currentTime/duration`，类别洗牌切歌后从左重走 | M |

### 3.4 场景与动效（FR-FX）

| 编号 | 需求 | 优先级 |
| :--- | :--- | :--- |
| FR-FX-01 | 背景从预置静帧（31 张）按标签命中分加权随机，禁止运行时生成；`defaults` 只作加分与无命中回退 | M |
| FR-FX-02 | 标签对应动效：grain / parallax / embers / raindrops / waves / ripples / fireflies / lightning / pulse | M |
| FR-FX-03 | 雨类玻璃水珠使用 WebGL（RaindropFX）；离开播放页不得销毁后使二次进入覆盖错误纹理 | M |
| FR-FX-04 | 溪流类水面涟漪：强度与频次均在范围内随机，且此落彼涨（强则疏、弱则密） | M |
| FR-FX-05 | 玻璃层与水面层失败时回退 2D，且不得用失败的不透明画布淹没静帧 | M |
| FR-FX-06 | 诗句轮换不得中断 WebGL 动效 | M |
| FR-FX-07 | 多轨标签动效取并集（如雨+火=玻璃雨+余烬），不得只保留一张静帧上的单一特效 | M |
| FR-FX-08 | 2D 动效应立即挂上；WebGL 成功后再让渡对应层。引擎快照每帧更新不得拆掉动效绑定 | M |

### 3.5 金句（FR-VS）

| 编号 | 需求 | 优先级 |
| :--- | :--- | :--- |
| FR-VS-01 | 按播放标签加权抽取金句，已出现次数产生惩罚 | M |
| FR-VS-02 | 版式（横/竖、位置）随机；按标点断行 | M |
| FR-VS-03 | 停留时长可调（约 6–40 秒）；到期淡出后换下一句，不得停在全透明 | S |
| FR-VS-04 | 曲库天气栏按时辰/天气展开标签加权抽句，界面仅渲染 `lines`，不显示题名与作者 | M |

### 3.6 持久化与接口（FR-API）

| 编号 | 需求 | 优先级 |
| :--- | :--- | :--- |
| FR-API-01 | 提供健康检查、目录、混音 CRUD | M |
| FR-API-02 | 混音 JSON 符合 `MixSchema`（schema_version = 1） | M |
| FR-API-03 | `/sounds`、`/backgrounds`、`/poetry` 范围请求由本机服务，不拷入前端包 | M |

## 4 非功能需求

| 编号 | 类别 | 需求 |
| :--- | :--- | :--- |
| NFR-01 | 安全 | 默认拒绝非回环绑定 |
| NFR-02 | 许可 | 启动路径展示个人使用声明 |
| NFR-03 | 性能 | 8 轨粒子/WebGL 有预算，不得无上限繁殖 |
| NFR-04 | 可用性 | 中文优先；播放页空格暂停/继续，Esc 停止回库，右方向键切下一首 |
| NFR-05 | 可维护 | 目录、模式、品牌常量集中定义 |
| NFR-06 | 兼容 | 目标 macOS 桌面 Chrome / Safari 最近两个大版本 |
| NFR-07 | 定位 | 天气优先本机地理定位；拒绝后可退到 IP 粗略位置；失败时仍按时辰组混音 |
| NFR-08 | 仓库 | 含 Apple Comfort Sounds 的完整素材仅允许私有仓库；禁止推送公开远程 |

## 5 接口需求

### 5.1 用户界面

两页：曲库 `/`、播放 `/play/{file\|category\|mix}/:id`。法律门覆盖二者。

### 5.2 软件接口

| 方法 | 路径 | 说明 |
| :--- | :--- | :--- |
| GET | `/api/health` | 健康与文件数 |
| GET | `/api/catalog` | 运行时目录 |
| GET | `/api/mixes` | 混音列表 |
| GET | `/api/mixes/:id` | 混音详情 |
| PUT | `/api/mixes/:id` | 保存（body.id 须匹配） |
| DELETE | `/api/mixes/:id` | 删除 |
| GET | `/sounds/*` | 音频，支持 Range |
| GET | `/backgrounds/*` | 静帧与背景目录 |
| GET | `/poetry/*` | 金句与标签 |

前端开发期由 Vite 将上述前缀代理到 Hono。

### 5.3 数据接口

混音文件：`data/mixes/<ULID>/mix.json`。字段见设计说明书第 5 节。
