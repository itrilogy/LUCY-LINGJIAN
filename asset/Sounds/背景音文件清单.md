# macOS 背景音文件清单（中文标注）

> **来源**：`系统设置 → 辅助功能 → 听觉 → 背景音`（Comfort Sounds）
> **原始位置**：`/System/Library/AssetsV2/com_apple_MobileAsset_ComfortSoundsAssets/`
> **文件总数**：87 个 ｜ **总大小**：约 508MB ｜ **格式**：Apple Lossless（.m4a）＋ 雷雨补充（WAV / MP3）
> **说明**：变体文件（如 Ocean_1 ~ Ocean_17）为同一类声音的不同版本，音色略有差异，可轮播挑选。
> **机器目录**：同目录 `catalog.json`（站点程序读取的权威索引）。

## 整理后目录

```
asset/Sounds/
  catalog.json                 # 机器可读目录（类别 + 文件元数据）
  背景音文件清单.md
  noise/     噪音类（4）
  traffic/   交通出行类（4）
  fire/      篝火 / 火声（13）
  rain/      雨声（18）
  ocean/     海洋 / 海浪（17）
  stream/    溪流 / 蒸汽（21）
  night/     夜晚（7）
  thunder/   雷雨天气（3）
```

各类别推荐播放页动效（写入 `catalog.json` 的 `effect` 字段）：`grain` / `parallax` / `embers` / `raindrops` / `waves` / `ripples` / `fireflies` / `lightning`。

## 备注

- 系统背景音（一~七）均为 Apple 官方原始资产（无损 m4a），可直接用「音乐」App / QuickTime 播放。
- 变体编号无特殊含义，仅代表同一声音类型的不同采样版本。同一 `variant_group` 的文件适合作为「整类随机」轨道的候选池。
- 雷雨文件（八）为网络补充下载，格式与来源见上表。
- 站点程序以 `catalog.json` 为权威索引，本 Markdown 为人读清单。
